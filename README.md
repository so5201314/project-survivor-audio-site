# Project Survivor · Audio & Development Showcase

这是 Project Survivor 的公开静态展示网站，用于展示项目世界观、美术方向，以及原创音乐和战斗音效试听。

## 页面入口

- `index.html`：网站入口。
- `web/`：页面样式、脚本与展示所需资源。
- `exports/ogg/`、`exports/wav/`：导出的音频文件。
- `exports/A02/`、`qa/A02/`：A02 音频批次相关文件与检查资料。
- `tools/optimize_images.py`：展示图片优化工具。
- `CREDITS.txt`：第三方音效来源与授权说明。

## 当前展示内容

- 《山海初见》：Project Survivor 的原创东方神话世界观与青岚谷道音乐展示。
- 战斗音效：用于试听剑击、攻击和碰撞等声音素材。
- 页面中的场景图和角色图用于美术展示，**不是游戏实机截图，也不代表对应关卡或动画已经在游戏中完成**。
